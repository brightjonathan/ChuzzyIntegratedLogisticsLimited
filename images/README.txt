PHOTOS
------
The site first looks for these local files and uses them if present; if not, it falls back to a free online photo; if that also fails, a branded navy background shows.
To use your own real photos, drop JPGs with these exact names into this folder (about 1600px wide, under 400 KB each is ideal):

  hero.jpg     - large hero background (trucks / terminal / cargo)
  about-1.jpg  - About section, main image (warehouse / operations)
  about-2.jpg  - About section, small image (containers / freight)
  port.jpg     - dark "Logistics That Works" section background

LOGOS
-----
  logo.png        - colour logo (transparent) used in the header
  logo-white.png  - white version used in the dark footer
  favicon.png     - browser tab icon
